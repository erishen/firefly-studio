## 🟡 中优先级任务

### P1-001: 优化数字归一化
- **状态**: 🔄 进行中
- **描述**: 数字朗读不正确，如"40"读成"四十零年"，"2.39亿"的点没读出来，"30°C"的度没读
- **解决方案**: 完善数字归一化逻辑，支持小数、百分比、温度、年份等
- **相关问题**:
  - "40" → "四十年"（不是"四十零年"）
  - "2.39亿" → "二点三九亿"
  - "30°C" → "三十度"
  - "100%" → "百分之百"

### P1-002: 优化文本预处理
- **状态**: ⏳ 待开始
- **描述**: 去除 LLM 返回文本中的多余换行、表情符号朗读、特殊符号处理
- **具体需求**:
  - 去除开头和结尾的空行
  - 表情符号不朗读（如 😊、🍜 等）
  - 波浪号（～）不朗读
  - 斜杠（/）在某些场景下跳过
  - Markdown 符号（#、*、`等）不朗读

### P1-003: 优化流式 TTS 体验
- **状态**: 🔄 进行中
- **描述**: LLM 文本先显示，然后语音才出来。应该先准备好语音，然后文字和口型一起出现
- **方案**: 打字机效果 + 流式 TTS
  - LLM 返回文本时，逐段进行 TTS 合成
  - 第一段 TTS 合成完成后，开始显示文字和播放语音
  - 后续段落边合成边播放，减少等待时间
- **当前状态**: 已实现基础版本，需要进一步优化

### P1-004: 音乐播放列表持久化
- **状态**: ⏳ 待开始
- **描述**: 添加的音乐重启后无法播放，因为 localStorage 只存了文件名，没有存文件路径
- **解决方案**:
  - 使用 Electron 的 fileSystem API 持久化文件路径
  - 或者将音乐文件复制到应用数据目录
  - 支持导入音乐文件夹

### P1-005: 优化 VAD 语音活动检测
- **状态**: ⏳ 待开始
- **描述**: VAD 状态切换过于频繁，导致语音分段不正确
- **解决方案**:
  - 增加语音确认阈值（连续 N 帧检测到语音才确认）
  - 增加静音确认阈值（连续 N 帧静音才确认结束）
  - 优化自适应阈值算法
  - 支持手动结束语音输入（长按麦克风按钮）
