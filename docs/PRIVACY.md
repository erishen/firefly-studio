# Firefly Studio 隐私政策（PRIVACY）

> 最后更新：2026-08-31
> 生效日期：2026-08-31

Firefly Studio（以下简称"本项目"、"我们"）重视用户隐私。本隐私政策说明本项目如何收集、使用、存储和保护您的信息。

本项目是一个**本地运行的桌面应用**，设计原则是**数据本地化、最小化收集**。绝大多数功能在您的设备上本地完成，不需要将数据发送到外部服务器。

---

## 1. 我们收集的信息

### 1.1 本地处理的信息（不上传）

以下信息仅在您的设备本地处理，**不会上传到任何服务器**：

| 信息类型 | 说明 | 存储位置 |
|---------|------|---------|
| **语音输入** | 麦克风采集的音频数据，用于本地语音识别（ASR） | 内存中临时处理，不持久化存储 |
| **语音识别结果** | ASR 转写的文字内容 | 内存中临时处理，可选择保存到聊天记录 |
| **聊天记录** | 您与数字人的对话内容 | 本地存储（应用数据目录） |
| **语音合成** | TTS 生成的音频数据 | 内存中临时播放，不持久化存储 |
| **设置偏好** | 应用设置、角色选择、音量等 | 本地存储（应用数据目录） |
| **播放列表** | 您添加的音乐文件信息 | 本地存储（localStorage） |

### 1.2 可能发送到外部的信息

以下信息可能会发送到外部服务器：

| 信息类型 | 说明 | 接收方 | 是否必需 |
|---------|------|--------|---------|
| **LLM 对话请求** | 您的消息内容，用于生成回复 | 您配置的 LLM 服务提供商（如 OpenAI、DeepSeek 等） | 是（聊天功能必需） |
| **模型下载** | 下载 ASR/TTS 模型时的网络请求 | HuggingFace、GitHub 等模型托管平台 | 否（首次使用时需要） |

### 1.3 我们不收集的信息

本项目**不会**收集以下信息：

- ❌ 您的姓名、邮箱、电话号码等个人身份信息
- ❌ 您的地理位置信息
- ❌ 您的设备标识符（如 MAC 地址、IMEI）
- ❌ 您的浏览历史或其他应用使用情况
- ❌ 您的联系人、相册、文件等个人数据
- ❌ 任何用于广告追踪或用户画像的信息

## 2. 我们如何使用信息

### 2.1 本地信息使用

- **语音输入**：用于本地语音识别（ASR），将您的语音转换为文字
- **聊天记录**：用于展示对话历史，支持上下文理解
- **设置偏好**：用于记忆您的个性化设置
- **播放列表**：用于管理您的音乐播放列表

### 2.2 外部信息使用

- **LLM 对话请求**：发送到您配置的 LLM 服务，用于生成数字人的回复
- **模型下载**：从模型托管平台下载 ASR/TTS 模型文件

---

## 3. 信息存储

### 3.1 本地存储

本项目的所有数据均存储在您的设备本地：

| 数据类型 | 存储位置 | 说明 |
|---------|---------|------|
| 应用设置 | 应用数据目录 | 使用 Electron `app.getPath('userData')` |
| 聊天记录 | 应用数据目录 | JSON 格式存储 |
| 播放列表 | localStorage | 浏览器本地存储 |
| 模型文件 | 应用数据目录 / 项目目录 | ASR/TTS 模型文件 |

### 3.2 数据保留

- **语音输入**：仅在内存中临时处理，处理完成后立即清除，不持久化
- **聊天记录**：保留在本地，直到您手动清除或卸载应用
- **设置偏好**：保留在本地，直到您手动重置或卸载应用
- **模型文件**：保留在本地，直到您手动删除

### 3.3 数据删除

您可以随时删除本地数据：

- **清除聊天记录**：在应用设置中选择"清除聊天记录"
- **清除播放列表**：在音乐播放器中选择"清空播放列表"
- **重置设置**：在应用设置中选择"恢复默认设置"
- **完全删除**：卸载应用并删除应用数据目录

## 4. 第三方服务

### 4.1 LLM 服务提供商

本项目支持配置多种 LLM 服务提供商。您的对话内容会发送到您选择的 LLM 服务提供商。请参考相应服务商的隐私政策：

- OpenAI：https://openai.com/privacy
- DeepSeek：https://www.deepseek.com/privacy
- 其他 OpenAI 兼容服务：请参考相应服务商的隐私政策

**建议**：如果您对隐私有较高要求，可以使用本地运行的 LLM 模型（如 Ollama），这样所有数据都在本地处理。

### 4.2 模型托管平台

首次使用时，本项目可能会从以下平台下载模型文件：

- HuggingFace：https://huggingface.co/privacy
- GitHub：https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement

下载过程中，平台可能会记录您的 IP 地址和下载请求。

## 5. 数据安全

### 5.1 本地安全

- 所有数据存储在您的设备本地，不会上传到云端
- 应用数据目录受操作系统权限保护
- 语音数据仅在内存中临时处理，不持久化

### 5.2 网络安全

- LLM 请求使用 HTTPS 加密传输
- 支持配置 API Key，API Key 存储在本地环境变量或配置文件中
- 建议不要在公共网络中使用敏感信息

### 5.3 安全建议

- 定期备份重要的聊天记录
- 不要在对话中输入敏感个人信息（如身份证号、银行卡号、密码等）
- 使用强密码保护您的设备
- 及时更新应用到最新版本

## 6. 儿童隐私

本项目不面向 13 岁以下儿童设计。我们不会故意收集 13 岁以下儿童的个人信息。如果您认为我们可能收集了儿童的信息，请联系我们，我们将立即删除。
